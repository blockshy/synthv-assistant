# 前端维护要求

- 修改前阅读 [前端规范](../docs/frontend-guidelines.md)，保持黑白工作台和既有主题令牌。
- 图标复用 `ui.js`，管理操作使用 `iconButton` / `setIconButton`；同时提供中文 `title`、`aria-label` 和必要状态属性。
- 主操作保留文字；不得绕过预览、确认、忙碌保护和错误反馈。新增代码使用具体、规范的中文注释。
- 尺寸、圆角和间距使用共享令牌，不追加针对单个页面的临时覆盖。响应式依据正文实际宽度处理。
- 修改后在项目根目录执行 `python scripts/check_frontend.py`，并对受影响页面做浏览器验收。只使用隔离数据，禁止将私人工程、录音、凭据或截图提交仓库。
