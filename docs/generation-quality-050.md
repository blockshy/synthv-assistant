# 参数生成与音高语义改进记录

核对日期：2026-11-10。本记录讨论生成逻辑与可重复验证，不把一次模拟测试或项目的自我介绍当成歌声音质评测。

## 已定位的问题

1. 旧规划器把“原生音高仅明确要求时使用”放在提示词中，后端没有独立的生成授权。模型即使只是收到“自然一点”，仍可能返回覆盖原演唱的绝对 MIDI 曲线。
2. 音高偏差和原生音高容易互相替代。前者是在现有表达上叠加音分，后者是原生控制曲线；用户要求绘制原生音高时，不能返回偏差曲线冒充完成。
3. 旧式音分包络默认在每个音符重复，同一唱法会被施加到短音、长音和跳进。任意整句折线也容易跨过具体音符。数值处于写入硬上限内，并不意味着修改有音乐依据。
4. “优化音高/声线”等目标没有位置和方向，模型仍会随意添加波峰。较小幅度也可能破坏原唱法，不能只靠增量限制解决。
5. 规划响应自动附加已经退役的音频和操作提示，混淆了模型建议与实际预览、应用状态。

## 当前生成契约

会话请求必须显式携带 `pitchPolicy`，缺省为 `preserve`。该策略来自界面/API 字段，不从模型回答、历史 reason 或自然语言关键词猜测授权。

| 策略 | 允许生成的音高操作 | 用户可见语义 |
| --- | --- | --- |
| `preserve` | 不允许 `pitchDelta` / `pitchCurve` | 保留音高；需要改音高时先确认处理方式。 |
| `local` | 仅 `pitchDelta` 的 `noteEdits` | 微调音高偏差：明确音符与部位，在已有表达上叠加小幅音分。 |
| `redraw` | 仅 `pitchCurve` 的 `pitchShape.notes` | 重绘原生音高：替换选区范围内的生成音高，不能偷偷改给偏差曲线。 |

工作台的自然语言不是对精确唱法的可靠测量。提示词要求在位置、方向或目标含糊时先提出一个简短问题，返回空动作；不能把“自然”自动解释成加气声、减张力或加正向音高波峰。这个要求是模型行为约束，不宣称后端可以可靠判定任意自然语言的真实意图。

### 确定性局部表达

`noteEdits` 是新规划器优先使用的结构：

```json
{
  "parameter": "tension",
  "noteEdits": [
    {"noteIndex": 2, "gesture": "body", "amount": -0.05}
  ],
  "reason": "按用户要求，轻微放松第2个选中音符的主体。"
}
```

- `noteIndex` 是选区内按实际秒数排序的序号，从 1 开始。它不是工程音符索引。
- `onset` 和 `release` 分别使用最多 120ms、180ms 的局部窗口，且不超过音符时长的 45%。`body` 在音符主体保持增量，两侧淡入淡出。非音高的 `swell` 表示渐强后渐弱。
- 音高偏差只允许明确的起音、主体或尾音目标；拒绝任意整体偏移、自由波峰和短于 120ms 音符的自动装饰。已有控制点、手工编辑与 MCP 硬契约仍保留。
- 输出编译成现有 `noteCurves` 来源和 `curve` 契约，未指定音符、休止和端点的请求增量为零。来源保存校准后的真实幅度，复用时按目标音符秒数重新换算。
- 每项最多 12 个目标，最终仍最多 64 个请求节点。超限明确失败，不静默删音符或节点。

零增量是请求语义；宿主插值、写入结果和边界保持仍由实际预览及写后检查核验。它不是对所有连续时刻都已精确保存的声明。复用已编译的 noteCurves 会保持相对包络；换到不同时长的目标音符，窗口也会随之缩放，用户需重新检查宿主预览。

### 逐音符原生重绘

新 AI 重绘必须使用 `pitchShape.notes`，不同音符使用不同相对乐谱音分包络，避免每个音符机械复制同一形状。未列出的音符使用平直乐谱基准；这仍是整个覆盖范围的替换，不能称为保留原演唱。短于 180ms 的音符不添加非零装饰。新 AI 不接受任意绝对折线和统一 `pitchShape.curve` 模板；既有历史/手工/MCP 绝对曲线契约继续保留，底层编译器也兼容旧式包络。遇到本契约不能表达的复杂目标，应明确说明限制，不能无声改成简化唱法。

重绘只表达乐谱和明确要求的形状，并不重建声库生成的颤音、滑音或发音细节。有限 `computedPitch` 数据可能有缺帧，也不是声学 F0 测量；本次不会将这些采样插值成完整原生基线，更不会据此自动纠正所谓跑调。

### 生成幅度预算

新模型方案先使用小于执行硬上限的工作台试调预算：气声/张力 0.12、性别 0.08、响度 2dB、局部音高偏差 25 音分、音色偏移 60 音分、颤音包络 0.15、浊音 0.10、声线 10 个参数百分点。宿主目录若更严格，服从较小值。这些数值是保守的产品起步策略，不是各声库的普适最佳唱法。

超预算时整条曲线等比减小，并在动作原因中说明；保持符号与相对形状，不逐点夹平。宿主 `currentValues` 的已知样本若显示剩余空间更小，同样等比收敛；若该方向没有空间，则拒绝生成零效果动作。缺少样本不补零、不拿默认值代替现值，也不声称有限样本可以证明整个连续曲线不越界。

## 离线验证与尚需试听的部分

`tests/test_generation_policy.py` 使用完全合成的乐句覆盖：默认禁止改音高、两种音高语义互斥、严格权限类型、局部时间窗、未选中目标零增量、短音限制、单位、整条缩放与复用来源一致、真实样本余量、缺少数据不造基线、64 节点预算和逐音符重绘。

现有 planner、pitch_shapes、parameters、tuning_quality 与 prompts 测试同步覆盖新契约。模型 HTTP 调用全部替身化，不调用真实服务、不读取用户密钥、不修改用户工程。

这些验证能证明范围、单位、结构和确定性规则；不能证明模型已理解全部音乐意图，也不能证明实际歌声优于用户原调教。原生曲线、声库声线和不同音高策略仍应在用户确认后，用真实宿主预览与试听判断。
