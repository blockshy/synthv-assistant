# Windows 原生桌面工作台（0.5.0）

本应用使用 Flutter 原生界面、受控 Python 本机后台和 SynthV Lua 桥接。模型负责文字咨询与参数建议，所有工程写入仍需“生成预览 → 用户确认 → 应用”。本版对照 SynthV Studio 2 Pro 2.3.0 官方资料更新；具体 API、声库差异与验证范围见源码仓库 `docs/synthv-230-support.md`。

## 启动与数据目录

解压完整 Windows x64 发行包，双击 `synthv_desktop.exe`。保留旁边的 DLL、Flutter 静态 `data` 资源及 `backend/`，不能只复制一个 EXE。后台随包提供，无需另外安装 Python 或 .NET；系统需有 Microsoft Visual C++ x64 运行库。当前没有代码签名或自动更新器。

| 运行方式 | 默认业务资料 |
| --- | --- |
| 完整发行包 | `%LOCALAPPDATA%\SynthV Assistant\data` |
| 源码启动 | 仓库根目录 `data/` |
| 指定 `SYNTHV_ASSISTANT_DATA` | 环境变量所指目录 |

业务资料包括会话、加密平台设置、模型缓存、桥接信息及旧音频。主题和侧栏宽度由桌面偏好存储管理。发行包不会扫描或搬移旧仓库；密钥由当前 Windows 账户 DPAPI 保护，复制资料到另一台电脑不代表凭据可用。

迁移或备份前等待任务结束，关闭相关程序。**旧网页和桌面不要同时管理同一业务目录。** 桥接目录可以与业务目录分开；连接原脚本不会自动迁移会话或密钥。

## 首次连接 SynthV

1. 在 Synthesizer V Studio 2 Pro 打开工程。
2. 打开工作台 **SynthV 连接**，刷新诊断。已安装脚本在线但目录不同时，可点击“连接正在运行的脚本”。
3. 新安装或更新桥接时使用“安装匹配脚本”；同名文件会先备份。随后在 SynthV 中结束旧脚本、重新扫描脚本并运行 **SynthV Assistant**。
4. 停止宿主播放并选中目标音符，在左侧“工程与参数”页面点击“读取选区”。心跳在线、脚本文件已安装和读取成功是不同状态。

**0.5.0 包含第 4 版桥接脚本，需安装并在宿主重新运行，才能使用新的采样校验及指定方案撤销。** 脚本更新不会自动修改工程。读取工程、选区和预览无需开启写入；应用前可在确认框勾选“允许修改当前选区”。该权限会保留在当前桥接工程，可到“工程与参数”关闭。切换桥接目标会使旧预览确认资格失效。

也可在发行目录使用 PowerShell 安装：

```powershell
# 仅读取计划，不写入脚本。
.\scripts\install-desktop-bridge.ps1 -WhatIf
# 备份并安装到固定的 SynthV Studio 2 用户脚本目录。
.\scripts\install-desktop-bridge.ps1
```

源码开发使用仓库 `scripts/install-bridge.ps1`。生成的 Lua 含本机 IPC 目录，不能直接拿其他机器生成的文件使用。改变资料目录后，需在连接页明确连接既有脚本或安装匹配目录的脚本。

## 模型服务与会话

“模型服务”采用平台列表与详情分栏，窄窗口切换列表/详情。添加服务预设，填写名称、协议、HTTPS API 地址和密钥后保存。默认模型允许为空；保存连接后到“模型目录”获取或手动填写型号，再保存默认模型。

密钥不回填。同协议和地址下留空沿用已保存密钥；改变服务类型或地址需重新填写。保存成功或失败后清空密码框。跨页、切换平台和重载前，未保存编辑可选择保存并继续、放弃或继续编辑。保存结果未知时先重新读取核对，不重复创建平台。

“设为新会话默认”只影响以后创建的会话。固定内置平台保留旧配置兼容身份，与新会话默认选择分别管理。停用沿用清除密钥和连接配置的语义，界面会明确确认，不能当作无损开关。

模型选择器一次确定平台与型号，支持缓存搜索和手动 ID。选择“平台默认”会显示实际型号；旧推理档位不适用于新模型时恢复默认并提示。打开选择器、搜索和切换服务只读本机缓存；明确刷新或测试连接才请求供应商目录。目录成功不保证推理能力或额度已验证。

发送流程：

1. 新建或选择会话，确定模型、推理强度、绘制模式及音高策略。
2. 输入文字目标，需要参数提案时显式勾选“附带选区”。
3. 发送后立即显示用户消息和真实任务进度；仅展示供应商实际返回的思考摘要。
4. 回复完成后点击“预览方案”，检查合并曲线，再点击“应用方案”核对参数、音符和范围后确认。

音高策略是请求的一部分：默认“保留原音高”禁止生成两种音高操作；“偏差微调”只允许指定音符起音、主体或尾音的局部音分叠加；“原生重绘”只允许替换原生音高曲线，不会失败后改用音高偏差。新建或打开另一会话会重置为保留，历史消息仍显示当时策略。原生重绘会覆盖旧演唱细节，不能将它理解为保留原唱法的微调。

模型应先指出具体目标和方向，再生成少量局部操作。模糊的“优化一下”应先澄清；本地编译按真实音符时长生成包络，使用小于手动编辑硬上限的试调预算，并在等比缩小幅度时显示说明。文字、乐谱和有限参数样本不能证明唱法或音准一定改善，仍需在宿主试听。

一项预览失败时整批不可应用；可以修正后重试，或明确选择“仅预览通过的 N 项”重新生成新批次。应用成功后的“撤销本次应用”只撤销该方案，不会撤销后来的其他修改。撤销成功后可重新预览并再次应用；宿主结果未知时先核对实际工程，不能重复点击写入。

纯文字咨询不需要宿主连接。没有选区时模型不能生成可执行参数动作。消息只携带必要历史文字及明确选择的安全工程摘要，历史音频不重新上传。流式调用按连续无有效输出时间判定超时，另有总时限；错误或断线不会自动重复收费请求。

## 工程与参数

原右侧检查器已移到独立主页面。宽屏左侧显示属性、右侧提供大画布；窄屏改为纵向排列，操作栏固定在页面底部。切页保留草稿并暂停隐藏页轮询，返回不会擅自重新读取选区。独立的“读取工程”和“读取选区”展示工程概况、宿主版本、音符组、真实音高排列及选区时间。参数按照通用参数、声库声线和原生音高组织，显示宿主返回的范围、有限采样现值、来源和不可用原因。

- `pitchDelta` 是相对原演唱的音分增量。
- `pitchCurve` 是官方 `PitchControlCurve` 原生绘制对象，使用绝对 MIDI 半音，属于替换原生音高的操作。
- `computedPitch` 是宿主计算音高的有限采样，仅以只读参考线显示；缺帧不补成零，不将其直接转成可写曲线。
- `vocalMode_*` 是宿主确认的声线自动化通道。`voiceValues` 中的 pitch/timbre/pronunciation 默认设置另行只读显示，不冒充曲线值。
- 声线目录可能只包含宿主已经暴露的模式，不声称完整枚举。未出现的声线须在宿主核对后由用户显式补充。

画布支持手绘、控制点增删拖动、草稿撤销与重置。音符和秒坐标提供编辑参考；原生音高草稿依据乐谱及组移调初始化，不能代表保留了原有演唱细节。数字节点编辑可用于精确调整，但不能绕过后端范围、复杂度和单次幅度限制。

点击“生成预览”只生成候选。底部固定栏保留预览、确认应用和“撤销最近一次修改”；该撤销是当前桥接最后一次修改，也可能来自会话，确认框会明确提示。真正应用前检查当前选区、参数指纹、预览票据和写入权限；写后校验异常或结果未知时不自动重放。完整撤销后可重新预览并确认。

AI 多参数提案使用组合预览：上方按音高排列音符，下方分参数绘制不同颜色曲线；不同单位不会叠成同一种音高。旧方案可“复用到当前选区”，在本机重新映射并校验，仍需新的预览和确认。

预览保留真实控制节点，并依据宿主插值自适应补充采样（最多 1024 个展示点），避免固定间隔漏掉短促变化；复杂度超限时要求缩小选区。普通参数默认显示调整前虚线和调整后实线，图例报告实际取值范围。音高偏差图显示写入后的音分参数值，原生图显示绝对 MIDI 曲线，两者均不是最终歌声的实测音高。实际写入保存同一候选快照，再校验完整节点与展示位置的插值；有限采样校验不等于连续区间的数学证明。

当前最多 128 个音符、30 秒连续范围。音符之间的休止也在影响区间内；共享组和无法安全处理的原生曲线边界会拒绝写入。实际效果需在 SynthV 中试听。

## 音频退役与历史资料

本版撤下音频素材、录音、试听、会话音频附件和 AI 听评入口，MCP 不再提供音频工具。不会自动删除已有 `recordings/`、`uploads/`、索引或历史消息；旧消息显示附件名称与历史标记，不再加载播放器或发送文件。

旧客户端的上传、录音、比较、听评 API 返回退役提示；带音频的消息在读取文件或排队前拒绝。历史受控读取与文件兼容代码保留，不能据此认为音频功能重新启用。新发行包不再携带 .NET 录音辅助程序。

回收站当前只展示会话。会话名称、星标和备注用于本地管理，不自动加入模型请求。永久删除需要明确确认；删除会话不删除独立历史音频、工程或桥接备份。

## 退出与排错

窗口关闭会核对正在执行的模型与宿主操作，忙碌或结果未知时保留窗口并提示。后台使用随机回环端口和内存令牌；不会向外网开放本机控制台，也不会把令牌放进媒体 URL。父进程意外退出后，后台有界收尾，不借退出跳过在途工程操作。

设置页原先的大片灰白区来自滚动位置与展开状态存储冲突。新版为展开状态、内部文本滚动分别建立存储边界；下拉控件统一高度、字体和边框。切换页面不应出现 ErrorWidget 或丢失未保存草稿。

“连接成功”仅代表桥接心跳；参数支持取决于当前宿主和声库实际返回。遇到异常先查看连接诊断、版本和当前选区，重新生成预览，不反复点击应用。

## 验证范围

自动化回归使用模拟供应商、Lua 宿主与隔离资料，覆盖参数校验、MCP 工具、页面往返、草稿保护、曲线编辑及正常退出。模拟验证不等于所有真实声库、复杂原生曲线或模型效果均已验收。测试不自动调用付费模型，也不在用户工程上自动应用参数。

开发与构建说明见源码 `desktop/README.md`。私有工程、密钥、历史音频、日志和验收截图不得加入公开仓库或发行包。
