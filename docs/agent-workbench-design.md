# Agent 工作台交互设计记录

## 目标与参考

桌面版 0.3.0 优先解决配置、选择和发送之间的断点：用户需要能看清正在编辑哪个平台、这条消息会使用哪个模型，以及配置保存到哪一步。

参考以下项目的官方产品说明，仅借鉴通用任务流程和信息层级，使用本项目 Flutter 组件独立实现。未复制这些项目的源码、CSS、品牌图标或截图资产，也未引入它们的运行框架。

| 参考 | 本项目采用的交互原则 |
| --- | --- |
| [Cherry Studio：配置服务商](https://www.cherryai.com/docs/en/pre-basic/providers/) | 平台列表与详情分开；先配置连接，再管理模型 |
| [Cherry Studio：服务商与模型](https://cherryai.com/docs/en/mobile/providers-and-models/) | 区分目录发现与模型调用，不把目录测试当作推理验收 |
| [Open WebUI：连接服务商](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/) | 服务商与模型分层，支持自定义兼容地址 |
| [Open WebUI：模型管理](https://docs.openwebui.com/features/workspace/models/) | 选择器按需展开，可搜索模型，常用操作保持简洁 |
| [LobeHub：服务商指南](https://github.com/lobehub/lobehub/blob/canary/docs/usage/providers.mdx) | 连接凭据、可用模型、会话选择各有明确位置 |

这些项目各有独立许可；本项目 MIT 许可不授予其源码或品牌资产的使用权。参考依据是公开产品行为，不以关注数量推断模型能力或产品质量。

## 配置流程

1. 从“模型服务”查看、搜索或新增平台。新增时选择已有协议的服务预设，或选择自定义兼容 API。
2. 填写名称、API 地址及密钥，保存连接。默认模型允许暂时留空，避免陷入“先有模型才能获取模型”的循环。
3. 在模型目录中显式获取供应商模型，或手动填写模型 ID；设置默认模型后再次保存。
4. 需要时设为新会话默认；已有会话不会因此切换平台。
5. 回到会话，通过一个选择入口同时确定平台与模型，再选择推理和曲线方式。

“模型服务”负责云端配置，“SynthV 连接”负责本机宿主桥接。二者在导航和文案上明确区分。

## 状态与作用范围

| 状态或操作 | 含义 |
| --- | --- |
| 未保存 | 当前编辑尚未提交；获取目录和连接测试使用已保存配置 |
| 连接已配置 | 协议、地址和凭据已保存，可以显式获取模型目录；不代表网络访问已验证 |
| 默认模型已配置 | 平台还保存了默认模型，可以作为新会话默认平台 |
| 目录连接测试成功 | 本次模型目录请求成功；不保证指定模型支持推理、音频或当前账户可调用 |
| 会话模型 | 一次选择保存平台 ID 与模型 ID；不会改动其他会话或平台默认值 |
| 使用平台默认 | 跟随所选平台的默认模型，选择器同时展示实际模型 ID |

固定的“默认配置”仍是原有 A/B 听评与 MCP 的兼容入口。“新会话默认”是另外一项偏好，不将二者混为同一种设置。

## 编辑与请求边界

- 离开配置页、切换平台、重新加载或新增前，未保存内容提供“保存并继续 / 放弃 / 继续编辑”。保存失败继续编辑，非密钥草稿保留。
- 密钥不回填。改变协议或端点不能沿用原密钥；保存后密码框清空。
- 停用沿用已有后端语义，会清除保存的连接配置与密钥，因此必须明确确认，不能表现成可随意恢复的开关。
- 打开页面、打开选择器、搜索及切换平台只读取本机缓存；获取目录和测试连接由用户点击触发。
- 目录请求不发送会话、工程或音频，也不生成模型回复。测试结果带配置版本；迟到结果不能验证另一份配置。
- 更换会话模型时，同时更新平台与型号。若旧推理档位不受新模型支持，恢复模型默认并明确提示。
- 缺少连接、缺少模型或已知不支持音频时，在发送前提供修改入口。后端仍执行最终校验。

## 界面约定与验证

继续采用灰阶工业工作台、统一 34 像素控件和固定操作栏。宽窗口使用平台列表与详情分栏，窄窗口使用列表/详情切换；长说明与超时设置按需展开。会话输入区只保留模型选择、推理和曲线模式，不放凭据或整张配置表。

回归重点包括：首次配置不要求先知道模型 ID、仅保存连接时不误发请求、平台与模型原子选择、缓存搜索不联网、旧响应不能覆盖新平台、跨页草稿保护、低分辨率操作栏可见。测试使用模拟供应商和隔离资料，不能据此宣称真实云端推理或听评已经通过。
