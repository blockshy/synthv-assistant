# 声线参数与曲线编辑

工作台通过 SynthV 的官方脚本对象生成曲线，不模拟鼠标点击宿主画笔，也不改写 `.svp` 文件。所有编辑仍经过“读取选区 → 预览 → 确认应用”；网页绘画、输入数值和模型返回方案都不会直接写入工程。

## 使用方式

1. 更新并重新运行 Lua 桥接，在 SynthV 选中目标音符，然后在工作台读取选区。
2. 在“调整参数”中选择通用参数、声线模式或原生音高曲线。面板中的声线未出现时，展开“补充声线模式”，按 SynthV 的原名添加，再选择该项。
3. 整段小幅修改使用“均匀增量”；需要随时间变化时选择曲线，在画布绘制或编辑数值点。时间位置为选区持续时间的比例，`0` 是起点，`1` 是终点，经过速度图换算后写到组内位置。
4. 默认采用精简曲线。通用参数可选密集控制点表示；原生音高只提供连续曲线。
5. 点击预览，核对宿主返回的时间、点数、曲线图和限制提示，再确认应用。图中显示参数数值，不表示模型已经试听或声音已经改善。

曲线输入为 2–64 个按时间严格递增的点，首尾位置必须是 `0` 和 `1`。同一选区最多 128 个音符、30 秒；音符间的空隙也属于连续目标范围。模型最多生成五项不同参数的建议，逐项预览和确认。

## 参数与单位

| 参数 | ID | 曲线数值含义及单次上限 |
|---|---|---|
| 气声、张力、性别 | `breathiness` / `tension` / `gender` | 相对原曲线的增量，±0.3 |
| 响度 | `loudness` | 相对增量，±6 dB |
| 音高偏移 | `pitchDelta` | 相对增量，±100 音分；不是绝对音高 |
| 音色偏移 | `toneShift` | 相对增量，±200 音分 |
| 颤音包络 | `vibratoEnv` | 相对增量，±0.3 |
| 声库声线模式 | `vocalMode_` 加宿主模式名 | 相对增量，±30 个百分点；总值限制在宿主公布的范围内 |
| 原生音高曲线 | `pitchCurve`（助手能力标识） | 工程绝对 MIDI 半音，例如 60 是 C4、60.5 是高 50 音分；同时受 0–127 和选区音符音域上下扩展 2 半音限制 |

实际可用项目由当前宿主能力决定。旧桥接仍可处理原有五种增量，新增参数和曲线需要新桥接。模型、Python 服务和 Lua 宿主会分别验证请求；模型不能自行虚构声库参数名称或扩大数值上限。

## 声库专属模式

声库模式首先从当前组与当前轨道主组的 `NoteGroupReference.getVoice().vocalModeParams` 中读取；工作台不把某个声库的名字列表硬编码到所有声库中。

官方接口没有承诺这个对象完整列出声库中所有未使用的模式，也可能保留以前的声线设置。请以当前声库面板为准。如果页面缺少一个可见模式，可通过“补充声线模式”按原名添加，例如 `Cute`。这只扩展当前组的目录，既不改变参数值，也不创建工程撤销记录；模型不能自行注册任意名称。

补充项标记 `source=user`，表示用户核对面板后的声明。宿主允许访问同名自动化通道，并不能证明该模式属于当前声库。名称区分大小写、不含控制字符，最长 80 个 UTF-8 字节。声明绑定当前工程、组位置、移调与声线设置，仅在本次桥接会话有效；重启桥接或切换到其他上下文后需重新补充。

本功能编辑模式的**自动化强度**。`getVoice()` 返回的 pitch、timbre、pronunciation 是组级声线设置，本版不把这三个全组设置冒充仅影响音符选区的曲线，也不自动修改它们。声线设置变化会让已有预览失效。

## 精简自动化曲线

SynthV 的通用参数使用 `Automation` 对象，底层仍是控制点。工作台的“精简”会去掉冗余采样，保留转折、边缘锚点和所有区外控制点；不会把通用参数伪装成不存在的原生笔画对象。

候选生成使用有界采样与误差检查，再通过独立宿主克隆验证插值。原曲线的插值类型保持不变。当前自动化编辑支持 `Linear`、`Cubic`；其他类型拒绝预览。复杂曲线需要更多点，无法满足采样误差或选区外保持检查时会明确拒绝，不静默扩大范围；有限采样不代表连续区间最大误差的严格证明。边缘有最多 80 毫秒的淡入淡出，避免从原值突然跳到偏移值。转折附近用约 1 毫秒的内部锚点约束切线，避免极短间距放大 float32 量化误差。原始或候选曲线超过 4000 点时拒绝处理。

“控制点”模式保留密集采样方案用于比较与兼容；默认使用精简方案。点数是整条参数曲线的点数，区外已有点不会因这次编辑被删除。减少点数本身不等于提高音质。

## 原生音高曲线

原生音高通过 `PitchControlCurve` 写入，是覆盖指定时间范围的连续音高对象，不是创建大量 `PitchControlPoint`。输入使用绝对 MIDI 音高，转换时包含音符组时间偏移与移调。已有且完全位于选区内的原生曲线会在确认后被替换；区外对象保留完整克隆。

2.2.1 真机中 `getValueAt()` 接收组内时间并返回已包含曲线锚点的组内音高，与文档的相对坐标表述不同。适配器先用不挂接工程的固定曲线校准，再逐节点核对实际候选；不会按版本名称猜测，也不会重复叠加锚点。无法唯一校准时关闭该能力并展示原因。

为避免改变选区之外的生成行为，以下情况会拒绝原生音高预览：

- 既有原生曲线跨越选区边界。
- 选区内存在原生音高引导点；移除这类点可能影响邻近生成音高。
- 选区内 `pitchDelta` 非零。官方文档未充分定义它与原生曲线的叠加顺序，工作台不会擅自清零，也不会从计算音高中猜测并重复叠加。
- 候选或现有数据超出大小限制、无法读取完整快照或宿主返回无效数值。

原生曲线不会自动“追踪原演唱音高”。当前没有可靠原曲线基线时，预览只展示候选曲线，明确说明未提供原曲线。对宿主实际插值进行有限采样核验，不把有限采样描述成对任意插值函数的数学证明。

## 接口与恢复

HTTP 使用 `POST /api/preview`；MCP 可调用 `preview_parameter` 或 `preview_curve`。参数增量与曲线互斥：

```json
{"parameter":"vocalMode_Airy","delta":10,"renderMode":"smooth"}
```

```json
{"parameter":"pitchDelta","curve":[[0,0],[0.3,30],[0.7,-20],[1,0]],"renderMode":"smooth"}
```

模型动作额外包含 `reason`，但不能包含代码或宿主指令。服务只公开经过白名单筛选的曲线采样与元数据，声线和完整曲线指纹不进入云模型上下文。

应用仍只接受 `previewId`，不会重新执行模型自由描述。应用前核对选区、速度图、组移调、声线设置与完整参数数据；建立一次撤销记录，写入后校验，失败尝试恢复原快照。恢复快照仅存在于当前桥接会话，重启桥接会丢失；软件原生撤销与已有工程备份继续保留。
