# 声线参数与曲线编辑

工作台通过 SynthV 的官方脚本对象生成曲线，不模拟鼠标点击宿主画笔，也不改写 `.svp` 文件。所有编辑仍经过“读取选区 → 预览 → 确认应用”；网页绘画、输入数值和模型返回方案都不会直接写入工程。

## 使用方式

1. 更新并重新运行 Lua 桥接，在 SynthV 选中目标音符，然后在工作台读取选区。
2. 在“调整参数”中选择通用参数、声线模式或原生音高曲线。面板中的声线未出现时，展开“补充声线模式”，按 SynthV 的原名添加，再选择该项。
3. 整段小幅修改使用“均匀增量”；需要随时间变化时选择曲线，在画布绘制或编辑数值点。时间位置为选区持续时间的比例，`0` 是起点，`1` 是终点，经过速度图换算后写到组内位置。
4. 默认采用绘制模式，通用参数使用精简曲线；也可选择控制点模式，保留密集采样。会话输入区有独立的模式选择，随会话保存并用于之后的请求；历史提案仍保留生成时的模式。原生音高只提供连续曲线，控制点模式的 AI 音高方案使用 `pitchDelta`。
5. 点击预览，核对宿主返回的时间、点数、曲线图、音符位置和限制提示，再确认应用。音符矩形是乐谱中的音高（含音符组移调），不是音频测得的基频；图中显示参数数值，不表示模型已经试听或声音已经改善。

曲线输入为 2–64 个按时间严格递增的点，首尾位置必须是 `0` 和 `1`。同一选区最多 128 个音符、30 秒；音符间的空隙也属于连续目标范围。模型最多生成五项不同参数的建议。单项建议直接预览，多项建议使用一次组合预览：失败项显示原因，用户只确认本次成功项组成的整批修改，不必为每项重复操作。该流程需要当前桥接返回 `capabilities.batchPreview=true`；旧脚本需更新并重新运行。

右侧手动原生音高草稿会为每个音符建立两个锚点、稳定段和短过渡，最多自动建立 32 个音符。音符过多、时间资料缺失或音符重叠时，会要求缩小或重新读取选区，不退回整句使用第一个音符音高的横线。

## 参数与单位

| 参数 | ID | 曲线数值含义及单次上限 |
|---|---|---|
| 气声、张力、性别 | `breathiness` / `tension` / `gender` | 相对原曲线的增量，±0.3 |
| 响度 | `loudness` | 相对增量，±6 dB |
| 音高偏移 | `pitchDelta` | 相对增量，±100 音分；不是绝对音高 |
| 音色偏移 | `toneShift` | 相对增量，±200 音分 |
| 颤音包络 | `vibratoEnv` | 相对增量，±0.3 |
| 声库声线模式 | `vocalMode_` 加宿主模式名 | 相对增量，±30 个百分点；总值限制在宿主公布的范围内 |
| 原生音高曲线 | `pitchCurve`（助手能力标识） | 工程绝对 MIDI 半音，例如 60 是 C4、60.5 是高 50 音分；同时受 0–127 和选区音符音域上下扩展 2 半音限制 |

实际可用项目由当前宿主能力决定。旧桥接仍可处理原有五种增量，新增参数和曲线需要新桥接。模型、Python 服务和 Lua 宿主会分别验证请求；模型不能自行虚构声库参数名称或扩大数值上限。

## 声库专属模式

声库模式首先从当前组与当前轨道主组的 `NoteGroupReference.getVoice().vocalModeParams` 中读取；工作台不把某个声库的名字列表硬编码到所有声库中。

官方接口没有承诺这个对象完整列出声库中所有未使用的模式，也可能保留以前的声线设置。请以当前声库面板为准。如果页面缺少一个可见模式，可通过“补充声线模式”按原名添加，例如 `Cute`。这只扩展当前组的目录，既不改变参数值，也不创建工程撤销记录；模型不能自行注册任意名称。

补充项标记 `source=user`，表示用户核对面板后的声明。宿主允许访问同名自动化通道，并不能证明该模式属于当前声库。名称区分大小写、不含控制字符，最长 80 个 UTF-8 字节。声明绑定当前工程、组位置、移调与声线设置，仅在本次桥接会话有效；重启桥接或切换到其他上下文后需重新补充。

本功能编辑模式的**自动化强度**。`getVoice()` 返回的 pitch、timbre、pronunciation 是组级声线设置，本版不把这三个全组设置冒充仅影响音符选区的曲线，也不自动修改它们。声线设置变化会让已有预览失效。

## 精简自动化曲线

SynthV 的通用参数使用 `Automation` 对象，底层仍是控制点。工作台的“精简”会去掉冗余采样，保留转折、边缘锚点和所有区外控制点；不会把通用参数伪装成不存在的原生笔画对象。

候选生成使用有界采样与误差检查，再通过独立宿主克隆验证插值。原曲线的插值类型保持不变。当前自动化编辑支持 `Linear`、`Cubic`；其他类型拒绝预览。复杂曲线需要更多点，无法满足采样误差或选区外保持检查时会明确拒绝，不静默扩大范围；有限采样不代表连续区间最大误差的严格证明。边缘有最多 80 毫秒的淡入淡出，避免从原值突然跳到偏移值。转折附近用约 1 毫秒的内部锚点约束切线，避免极短间距放大 float32 量化误差。原始或候选曲线超过 4000 点时拒绝处理。

三次插值在新增选区边界后可能改变相邻切线。对此，候选会在独立克隆中按需补充区外保护点，其值取自原曲线；所有原区外节点仍保留，每轮重新检查区外插值，原误差阈值不放宽。新增保护点最多 512 个，整条曲线仍受 4000 点上限约束；预览会提示实际补点数。保护点只用于保持原形状，不加入调教增量；无法收敛时继续拒绝，不保证所有气声曲线都能通过。本轮真机选区的气声仍因该保护检查拒绝预览。

“控制点”模式保留密集采样方案用于比较与兼容；默认使用精简方案。点数是整条参数曲线的点数，区外已有点不会因这次编辑被删除。减少点数本身不等于提高音质。

气声等参数仍执行严格的边界和插值检查，不能以扩大修改范围、忽略区外变化或清除旧曲线的方式强行通过预览。已识别的失败会显示具体原因；通过某个测试选区不代表所有声库、曲线和插值组合都能通过。

## 原生音高曲线

原生音高通过 `PitchControlCurve` 写入，是覆盖指定时间范围的连续音高对象，不是创建大量 `PitchControlPoint`。输入使用绝对 MIDI 音高，转换时包含音符组时间偏移与移调。已有且完全位于选区内的原生曲线会在确认后被替换；区外对象保留完整克隆。

已有连续曲线允许仅含一个节点，范围以锚点加节点偏移计算；位于选区内时可被新曲线替换，区外则保留。空连续曲线原样保留，不阻挡预览。这不改变新建候选需要至少两个节点的规则，也不会把连续曲线当成影响邻近生成音高的引导点。

2.2.1 真机中 `getValueAt()` 接收组内时间并返回已包含曲线锚点的组内音高，与文档的相对坐标表述不同。适配器先用不挂接工程的固定曲线校准，再逐节点核对实际候选；不会按版本名称猜测，也不会重复叠加锚点。无法唯一校准时关闭该能力并展示原因。

为避免改变选区之外的生成行为，以下情况会拒绝原生音高预览：

- 既有原生曲线跨越选区边界。
- 选区内存在原生音高引导点；移除这类点可能影响邻近生成音高。
- 选区内 `pitchDelta` 非零。官方文档未充分定义它与原生曲线的叠加顺序，工作台不会擅自清零，也不会从计算音高中猜测并重复叠加。
- 候选或现有数据超出大小限制、无法读取完整快照或宿主返回无效数值。

会话预览遇到这些已知拒绝时会显示具体原因与处理建议，而非统一提示桥接或选区故障。错误文本由服务端固定白名单产生；未知宿主异常仍使用通用提示，不公开异常中的本机路径或其他私有数据。

新版桥接在读取选区时就检查 pitchDelta 兼容状态：已有非零偏移或无法可靠确认时，将 `pitchCurve` 目录项标记为不可用。模型收到的可用目录据此引导它使用允许的小幅 `pitchDelta`，不继续生成无法预览的原生曲线。既有音高保持完整；已经保存的原生提案不会被自动改写，用户需重新规划或自行在 SynthV 处理后重读选区。

原生曲线不会自动“追踪原演唱音高”。当前没有可靠原曲线基线时，预览只展示候选曲线，明确说明未提供原曲线。对宿主实际插值进行有限采样核验，不把有限采样描述成对任意插值函数的数学证明。

### 按音符生成 AI 音高方案

绘制模式下，AI 原生音高建议优先使用 `pitchShape`，描述每个音符内部相对其乐谱音高的音分包络。单个偏移限制在 ±50 音分，过渡时长 `transitionMs` 为 5～120 毫秒；本机按已读取的真实音符起止秒数、音高和音符组移调，把包络编译为绝对 MIDI 曲线，不让模型凭整段起止音高画一条跨越所有音符的粗略折线。

编译后的曲线仍最多 64 个节点。若选区太长、短音符太密或包络复杂而无法满足限制，服务会提示缩短选区，不抽掉短音符来凑点数。模型直接返回绝对曲线时，还会在每个音符内部的 25%、50%、75% 位置检查其与乐谱音高的偏离，拦截跨音符拉直造成的明显错误。这些检查提供结构约束，不代替试听，也不保证所有演唱风格适合相同包络。

会话预览也会重新检查旧提案，并检查宿主真实采样：命中音符主体 25%～75% 区间的样本若偏离乐谱超过 0.75 半音，会拒绝提供确认入口。极短音符可能没有被固定采样命中，此时不二次插值推测其宿主效果；输入节点的逐音符检查与后续试听仍然必要。旧版生成的不合旋律提案需要重新规划，不会在预览时偷偷改写。

正式曲线图只绘制宿主返回的候选采样。上方音符轨作为乐谱参照，与缺失的“修改前演唱音高”明确区分；不会用矩形顶边补造原曲线。

## 音符与参数分轨预览

预览中的音符按音高上下排列，横向长度表示音符时值，位置与当前预览快照的时间一致。左侧键盘和半音网格用于对照音名；较高音符位于上方，同音高音符才处于同一行。所有参数都使用这种音符排列，不再把不同音高的音符排成单行时间条。

- **上方音符轨**：保留钢琴键、半音网格及实际 MIDI 排列。音符已经包含组移调，显示时不会重复叠加。
- **下方参数轨**：所有正式预览都与音符分轨并共用时间横轴，包括原生音高、音高偏移、气声和声线等参数。单参数保留其原单位，例如原生音高为 MIDI、偏移为音分，不将它们再次投影到音符块上。
- **组合曲线**：最多五个参数用不同主题颜色叠在同一条下方参数轨，每个参数按自己的显示量程归一化到 0–100%。图例列明原量程与单位，指针读数保留原始数值；颜色与百分比只用于比较变化位置和形状，不代表不同参数的绝对值可以直接相比。每条曲线可以隐藏或显示，调整前数据可作为同色虚线开启。
- **绘制模式与控制点模式**：连线数值来自宿主提供的曲线采样；控制点标记只来自 points 模式的宿主实际候选节点，不给固定间隔的预览采样补圆点。smooth 保持连续线条。未知或缺失的调整前数据保持空缺，不能补零，也不能跨缺失区间连线。
- **历史范围检查**：组合图要求可靠且一致的起止时间和音符快照。不同选区或缺少共同时间依据的旧预览拒绝混画，需重新生成组合预览。

音符、曲线、节点均使用对应预览保存的数据，切换工程或选区不会改变历史图像的含义。旧预览缺少音符时仅显示已有参数曲线，并提示重新预览以取得音符位置，不从当前选区补造旧预览。图中的音符是乐谱参照，不是测得基频；原曲线缺失时不会由音符、草稿或当前工程推算补齐。数值与时间可通过预览明细和音符列表核对，图形本身不表示修改已应用。

右侧手动音高草稿保留叠加编辑视图，与正式分轨预览区分：原生音高草稿与音符共用 MIDI 纵轴；音高偏移草稿按“乐谱 MIDI 音高 + 音分增量 / 100”显示参考曲线。偏移草稿的鼠标落点按所在音符换算回音分增量，数值输入和提交仍是音分，不能作为绝对 MIDI 提交；休止处没有音符基线，不能直接落点。参考曲线按音符边界分段，重叠或缺少有效音符时回退原单位视图。草稿只表示拟编辑数值，正式预览才包含宿主原参数、淡入淡出和范围限制后的候选值。

正式分轨显示使用预览已经保存的音符和参数数据，刷新网页即可采用新布局。取得真实节点需要支持 `controlPoints` 的桥接；组合预览和整批应用另外要求 `batchPreview` 能力，不能仅刷新网页就让旧脚本获得这些写入能力。

## 接口与恢复

HTTP 使用 `POST /api/preview`；MCP 可调用 `preview_parameter` 或 `preview_curve`。参数增量与曲线互斥：

```json
{"parameter":"vocalMode_Airy","delta":10,"renderMode":"smooth"}
```

```json
{"parameter":"pitchDelta","curve":[[0,0],[0.3,30],[0.7,-20],[1,0]],"renderMode":"smooth"}
```

模型动作额外包含 `reason`，但不能包含代码或宿主指令。服务只公开经过白名单筛选的曲线采样与元数据，声线和完整曲线指纹不进入云模型上下文。

手动或单项应用使用宿主返回的 `previewId`，不会重新执行模型自由描述。会话组合预览使用 `POST /api/assistant/batches/preview` 和同一条消息的 `actionIds`；响应中的 `actions` 返回所有请求项的最新状态，`errors` 明列失败项。只有带当前 `batchId` 且成功预览的项组成确认集合。组合应用使用 `POST /api/assistant/batches/apply`，只提交这个 `batchId`，不能临时增删参数或单独应用某个批内预览。

应用前核对选区、速度图、组移调、声线设置与完整参数数据；整批确认后建立一条 SynthV 撤销记录，写后验证全部参数，异常时尝试恢复整组原快照。成功的组合操作可一次撤销或通过“恢复最后修改”整组恢复；无法核实的返回仍保持 `unknown`，不自动重放。新预览会使旧确认凭据失效。恢复快照保留当前桥接会话最近一次修改；组合应用失败且自动回滚未完成时，也会记录各参数实际残留状态并保存待恢复记录，后续恢复仍先核对工程未被再次修改。重启桥接会丢失该内存记录；软件原生撤销与已有工程备份继续保留。

会话中已经确认成功应用的提案，可在撤销或恢复后重新预览：单项使用“撤销后重新预览”，组合使用“重新生成组合预览”。后端要求原桥接会话、选区和目标参数完整指纹都恢复一致；验证通过后清除旧应用结果和预览编号，生成新的宿主预览，再等待用户确认。未撤销、撤销不完整、继续编辑、旧桥接缺少完整指纹或应用结果未知时，都不能据此重复写入。

- [NoteGroupReference.getVoice](https://resource.dreamtonics.com/scripting/NoteGroupReference.html#getVoice)：2.1.1 起的声线分项设置。
