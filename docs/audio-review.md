# 对话模型、音频素材与可选听评

三栏工作台以对话为中心，左侧管理持久会话、素材与模型平台设置，右侧保留工程检查、手动调参及 A/B 试听。本地分析不联网。对话可仅发送文字，也可显式附带选区和音频；没有音频附件时，不要求模型支持音频输入，也不会自动发送历史音频。

配置模型后，点击发送消息或提交听评才会发出生成请求；显式刷新模型目录会另行向所选平台请求模型列表，但不附带会话、选区或音频。上传到本地素材库、保存模型设置、读取会话、查询本地能力规则和生成宿主参数预览本身都不调用云模型。协议与流程测试使用虚构凭据、模拟响应和隔离模拟宿主，真实云模型尚未验证。

## 文字咨询与参数规划

每条消息最多 4000 字符。取消“附带当前选区”时可以纯文字咨询，不需要已连接的 SynthV；回复不会包含可执行动作。勾选该选项时，服务必须成功读取非空选区，否则明确拒绝本次请求。模型获得音符、组音高偏移、时间范围、真实参数目录的标签/单位/类型/限幅及可用能力，不获得工程绝对路径、内部组标识、桥接会话、声库原始文件信息或私有指纹。

纯文字请求使用所选协议的文字输入分支，文字模型即可参与咨询与规划。附带 WAV 或 MP3 转换后的音频时，服务才加入真实音频内容，所选模型必须支持相应音频输入格式。两个分支都使用本会话选择的平台、模型与推理强度；平台默认模型仅在会话模型留空时生效。保存配置后的下一次请求会重新读取所选平台，已经开始的请求继续使用原完整快照。

每次请求最多带入最近 8 条文字历史，每条最多 2000 字符。历史中的音频附件只保留会话展示信息，**不会自动再次上传**。模型输出的参数建议需要先在提案卡片生成宿主实际预览，再由用户逐项确认；发送消息不会直接改动工程。

## 会话模型选择、进度与思考摘要

会话输入区可以选择平台、填写模型 ID 和选择推理强度。这些选项随当前会话保存，不改写平台全局默认值或其他会话。模型留空使用该平台默认模型；推理选“模型默认”时完全省略额外强度参数，“关闭”则是部分模型支持的显式设置，两者不同。

点击发送后，用户消息立即出现在对话中，无需等待模型结束。服务端保存的正式记录返回后会替换本地待发送展示，避免同一条消息出现两次。发送失败会保留明确状态，不自动重发请求；已有消息不代表模型已经完成回复或参数已经应用。

设置页支持将已保存且已配置的平台“设为新会话默认”。偏好保存于平台注册表，后续创建会话时写入对应平台编号、空模型覆盖值和默认推理强度，已有会话不受影响。该偏好与原有 `default` 配置入口不同，独立 A/B 听评继续使用原配置。停用所选默认平台时，新会话偏好回退到原有 `default` 平台，界面显示实际结果。

推理档位由本地规则按系列提供。OpenAI / 兼容协议及 Qwen 3.8 使用 `reasoning_effort`，Gemini 按系列使用 `thinkingLevel` 或 `thinkingBudget`。已知不支持的档位会被拒绝；切换模型后，不兼容的旧档位需由用户重新选择，服务不自动降低强度。未知兼容模型的可选值只是协议尝试，实际是否支持取决于平台。明确不支持音频的模型会在加载和外发附件前被拒绝；未知能力不被当成已经验证。

网页聊天接收 SSE 流式回复，并显示实际阶段、等待时间和已接收字符数。OpenAI 兼容服务及 Qwen 需支持对应 Chat Completions 流式响应；Gemini 使用 `streamGenerateContent?alt=sse`。不支持流式、超时或返回异常时会明确失败，不自动改用非流式或重新计费调用。独立 A/B 听评和 MCP 听评按所选协议执行，并在完成后返回整段听评文字。

平台中的“响应等待超时”（5～180 秒）用于流式会话的连接、首次有效输出和相邻有效输出之间的等待。收到新的非空正文或供应商公开思考摘要时重新计时，因此持续输出不会在 60 或 180 秒时被总时限截断；摘要达到本地展示上限后，后续有效摘要仍会续期。纯 SSE 心跳、注释和空事件不算模型输出。每次流式请求另有 30 分钟总上限，并保留响应大小限制，防止无限响应。错误会区分等待首次输出、输出中断及总上限；已收到的公开摘要会保留，但不完整响应不会变成可应用提案，也不会自动重试。

网页持续查询同一个后台任务，直到服务端返回完成或失败，不再另设 10 分钟总等待上限。浏览器与本地服务的每次 HTTP 请求仍有连接等待保护；连接断开时显示错误，不重发模型任务。Qwen Omni 的独立 A/B 听评在内部聚合流式响应，同样按有效正文或思考内容续期并保留 30 分钟总上限，但不向网页逐字显示听评进度。其他非流式听评仍将平台数值用作普通 HTTP 等待超时。

只有供应商实际返回可见思考摘要时，页面才展示摘要；支持的 Gemini 请求会请求 `includeThoughts`，其他平台是否返回相关字段取决于其实现。没有摘要时会说明未收到，工作台不会模拟思考、补写过程或声称能读取隐藏内容。摘要最多保留 12000 字符，经过密钥及跨事件凭据片段脱敏后用于本地展示；即使最终计划失败，已收到的安全摘要也可留在错误消息中。

摘要不会加入下一轮文字历史，也不作为参数动作或系统指令。正文片段只有在响应完整结束并通过严格 JSON、参数白名单、限幅与选区校验后，才形成正式回复及提案。流式返回文本不等于实时传输音频：附件仍是发送时选定的完整 WAV，不会自动持续采集或上传麦克风。

## 本地上传与本次附件

通过“音频素材”上传 WAV/MP3，或选择已完成的 SynthV 工程录音。上传只落在本机素材目录，不会立即传给云服务。当前上传限制为：

- 单个原文件和转换后的 WAV 均不超过 **12,000,000 字节**；上传片段时长大于 0 且不超过 **60 秒**。
- WAV 需为完整的 16、24 或 32 位整数 PCM。MP3 通过本机 `PATH` 中的 FFmpeg 转为 WAV；缺少 FFmpeg 或转换失败时明确报错，不自动安装工具。
- 超长或损坏音频整体拒绝，不保存悄悄截断的版本。
- 每条消息最多显式选择 **2 个**附件，实际 WAV 合计不超过 **12,000,000 字节**；不选择附件也可以发送文字。

MP3 的本地转换不代表模型已经听过音频。只有把素材加入本次消息并点击发送，才会进入该次模型请求。附件按受控素材/录音编号解析，不能通过消息参数指定任意本机路径。

录音页可以独立“读取选区”，立即读取 SynthV 当前范围后填写录音起点和时长，无需先在右侧读取。读取失败或没有有效选区会清空旧范围；也可手动填写。录音范围按 1～30 秒限制填写，超长选区只取前 30 秒并提示。录制及把结果附到会话仍是本地操作，只有发送该条消息才会上传音频。

## 本地技术分析

`analyze_wav(path)` 接受 16、24、32 位小端整数 PCM WAV，最大 128 MiB。Python 3.10 的 `wave` 不支持所有 WAVE_FORMAT_EXTENSIBLE / 浮点 WAV；这些文件请先转为普通整数 PCM WAV。

返回字段：`duration` 秒、`sampleRate` Hz、`channels`、`sampleWidth` 字节、`frames`、`peakDbfs`、`rmsDbfs`、`clippingRatio`、`silent`、`warnings` 和最多 300 点的 `envelope`。每个包络点包含窗口中心 `time`（秒）、`peak` 和 `rms`（线性振幅）。数字静音的分贝为 `null`，避免产生不合法的 JSON Infinity。

RMS 对所有声道的平方采样值求平均，不先混合声道。RMS 不是 LUFS：这里没有频率加权、响度门限或感知模型。`clippingRatio` 是触及整数 PCM 正负轨值的采样比例，只提示潜在削波，不单独证明失真。`silent` 表示峰值不高于 -80 dBFS。

`compare_wavs(before, after)` 返回两份完整分析和“修改后减修改前”的汇总差。它不进行时间对齐、响度归一化或重采样，不生成音准、自然度或质量评分。不同片段长度、声道路由和音量会影响比较，应优先使用相同范围、相同输出设置的短片段。

## 供应商配置

### 网页即时配置

左侧设置与 A/B 音频评审入口打开同一个中央设置页面。页面可管理最多 20 个平台（包含默认平台），每个平台有名称、协议、默认模型、HTTPS API 根地址、API key 和 5～180 秒响应等待超时。流式请求的有效输出会续期，非流式请求使用普通 HTTP 等待超时。可选择停用、OpenAI / OpenAI 兼容服务、Gemini 或通义千问 Qwen。更换协议会填入相应默认模型和地址，不会自动提交；纯文字使用时可以改为文字模型。离开设置页会清空尚未保存的密钥输入；已经保存的密钥仍由本机账户加密保护。

原有配置固定为 `default` 平台，继续保存在 `data/audio-settings.json`，无需迁移。其他命名平台保存至 `data/model-platforms.json`，不会自动继承默认平台或环境中的密钥。两份文件均使用当前 Windows 账户的 DPAPI 加密完整配置。点击“保存并立即生效”后，下次启动保留，后续使用该平台的请求立即读取新设置，无需重启。独立 A/B 听评及 MCP `review_recordings` 仍使用默认平台，不会跟随网页当前会话的平台选择。保存动作不会连接供应商或发送录音，因此“已配置”不代表密钥有效、账户有权限或模型能够接收音频。

设置接口只返回公开字段及 `keyConfigured`，不返回密钥、密文、密钥长度或片段。密码框使用密码输入类型，取消、关闭或保存失败后清空；不使用浏览器本地存储或 URL 传递密钥。同一供应商及规范化 API 根地址不变时，空白密钥表示保留；更改其中任意一项都必须重新输入，避免将旧凭据发到新服务。

“清除密钥并停用”会为当前编辑平台保存不含密钥的 `none` 状态，不影响其他平台；默认平台的停用状态覆盖环境变量后备，不会删除本地文件后重新启用环境密钥。选择停用后保存效果相同。默认平台保留原设置 revision，其他平台共享平台注册表 revision；版本冲突时拒绝静默覆盖，需重新加载后提交。非秘密字段在保存失败时保留，密钥需重新输入。

网页使用 `GET /api/model-platforms`、`GET /api/model-platforms/{id}` 读取公开配置，使用 `POST /api/model-platforms` 创建或编辑平台。会话选项通过 `POST /api/conversations/{id}/model-options` 保存。旧 `GET/POST /api/audio-settings` 和 `POST /api/audio-settings/clear` 保留为默认平台兼容入口。这些请求都通过 `/api/bootstrap` 获取本地会话令牌并以 `X-SV-Token` 发送；令牌不是供应商 API key。设置轮询与状态刷新不会覆盖打开中的表单草稿。

### 模型目录缓存与显式刷新

在会话模型输入框旁点击刷新按钮，才会调用本地 `POST /api/model-platforms/{id}/models`。OpenAI 与 Gemini 向各自配置根路径下的 `/models` 发送 GET；Qwen 使用已确认官方域名下的原生 `/api/v1/models`，读取 `output.models` 并以 `page_no`、`page_size` 分页，不假设 OpenAI 兼容目录存在。OpenAI / Qwen 使用 Bearer 认证，Gemini 使用 `x-goog-api-key`；请求仅用于获取目录，不发送消息历史、歌词或录音。不跟随自动重定向，分页只在同一配置端点内进行；最多获取 5 页、500 个条目，每页不超过 2 MB，并使用不超过 30 秒的请求超时。未适配的 Qwen 自定义目录端点明确返回提示，可继续手填模型 ID，不自动将密钥转交其他域名。

返回条目只包含模型 ID 与展示名称。Gemini 过滤不支持 `generateContent` 的条目，并移除 ID 的 `models/` 前缀；重复或不能安全填写的 ID 不进入候选列表。达到本地限制时目录可能不完整，接口失败时可继续手动填写模型 ID。目录里出现某个名称不证明它支持音频、流式回复、所有推理档位或当前账户可调用。

获取成功后，脱敏条目保存到 `data/model-catalogs/{platformId}.json`，包含获取时间和分页状态。缓存身份绑定平台 ID、协议、API 地址和凭据；身份摘要经过当前 Windows 账户的 DPAPI 加密后保存，不额外留下可用于猜测弱密钥的明文摘要。模型名称与时间本身不加密，仍属于本机数据，不应随仓库发布。

打开页面、新会话或切换平台使用带本地令牌的 `GET /api/model-platforms/{id}/models`，仅检查本地缓存。未命中、损坏、解密失败或配置变化时返回空缓存并保留手填入口，不自动转为供应商请求。跨网页刷新和服务重启继续复用；超过 7 天标记 `stale`，仍可使用。名称、默认模型和超时变化不改变连接身份，因此不导致无谓失效。主动刷新成功原子替换缓存，刷新失败保留旧目录；缓存保存失败只提示未保存，不丢弃已获取的列表。

页面的能力提示通过本地规则查询，不会为探测能力而自动发送模型请求。目录读取、能力规则和实际生成属于不同证据：最终支持情况仍需在所选平台的真实调用中确认，项目尚未完成真实云端验收。

这三款提供“模型默认、关闭、低、中、极高”档位，分别对应不传额外强度、`none`、`low`、`medium`、`xhigh`。默认档位不代表关闭，服务端当前默认开启思考并使用 `xhigh`。请求只传 `reasoning_effort`，不同时设置 `thinking_budget`；工作台不把兼容映射的 `high` / `max` 伪装成不同推理能力。思考内容仍仅展示供应商实际返回的公开字段。项目不将展示摘要回灌为完整历史思考，因此显式关闭 `preserve_thinking`，文字历史正常保留。[官方推理参数](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)

Qwen Omni 的本地音频通过 `input_audio` 发送，`data` 使用 `data:;base64,...`，格式为工作台校验后的 WAV，输出模态固定为文字。官方要求单段编码后的 Base64 字符串小于 **10 MB**；项目还保留上述 60 秒上传、附件数量和合计字节限制，较宽松的供应商时长上限不会放宽本地上限。超出限制时先在本地拒绝，不悄悄裁剪或改传公网文件。A/B 听评也执行供应商限制。[Omni 本地文件与音频限制](https://help.aliyun.com/zh/model-studio/qwen-omni)

百炼 Qwen 目录只在显式刷新时访问官方原生模型列表 API，成功后复用同一套本机缓存规则。目录出现型号不代表音频可用，附件能力仍以已适配模型规则校验。协议和错误分支已用模拟响应验证；尚未使用真实平台密钥完成云端文字、思考摘要或音频听评验收。[原生模型目录接口](https://help.aliyun.com/zh/model-studio/list-models)

### 环境变量后备

仅在默认平台没有本机保存文件时，启动进程中的环境变量作为其后备配置。网页本机配置优先；本地文件损坏、无法读取或无法解密时停止相应模型请求，不回退到环境密钥。新增命名平台没有环境后备。环境变量自身的更改仍需重启进程，网页保存不需要重启。`.env.example` 是字段说明，程序不会自动读取 `.env`。不要把真实 API key 写入源文件、提示词、截图或版本控制。

| 环境变量 | 含义 |
|---|---|
| `SYNTHV_AUDIO_PROVIDER` | `openai`、`gemini` 或 `qwen`；空值/`none` 禁用。单独存在 key 不会启用上传。 |
| `SYNTHV_AUDIO_MODEL` | 可选模型 ID；留空时使用 `settings.py` 中的默认值。请按所选服务及账户实际权限配置，默认值不保证可调用。 |
| `OPENAI_API_KEY` | OpenAI key；仅选择 OpenAI 时读取使用。 |
| `GEMINI_API_KEY` | Gemini key；仅选择 Gemini 时读取使用。 |
| `DASHSCOPE_API_KEY` | 对应所填 Qwen 平台地址的 key；仅选择 Qwen 时读取使用，不继承 OpenAI / Gemini 密钥。 |
| `SYNTHV_AUDIO_BASE_URL` | 可选 HTTPS API 根路径；默认 OpenAI `https://api.openai.com/v1`，Gemini `https://generativelanguage.googleapis.com/v1beta`，Qwen `https://dashscope.aliyuncs.com/compatible-mode/v1`。不填写完整方法地址。 |
| `SYNTHV_AUDIO_TIMEOUT_SECONDS` | 默认 60 秒，范围 5～180 秒。流式会话及 Qwen Omni 流式听评用于连接、首次有效输出与有效输出间的等待；有效输出续期，另有 30 分钟总上限。其他非流式调用为普通 HTTP 等待超时。 |

自定义根路径会接收供应商 key、本次文字与上下文，以及显式选择的音频，只应填写你信任的兼容服务。OpenAI 兼容服务在处理音频附件时必须支持 `input_audio`；纯文字分支不发送该字段。实现拒绝 HTTP 明文、URL 用户名密码、查询参数和自动重定向。普通状态接口不回显 key 或自定义根路径；受会话令牌保护的设置接口可返回用户填写的非秘密根路径供继续编辑，但始终不返回 key。

## 听评调用与边界

A/B 评审使用默认平台的独立接口 `review_audio(paths, prompt, context=None)`，接受 1～2 个完整整数 PCM WAV，每个不超过 120 秒，所有文件合计不超过 12,000,000 字节，完整 JSON 请求不超过 18 MB。这个内部接口上限不改变网页上传入口的 60 秒限制。两个文件按顺序标记为 A（修改前）、B（修改后）。本版使用内联音频，不使用供应商 Files API，也不做实时音频传输；A/B 独立听评仍按完整响应返回文字。

Qwen 平台的听评需选择 `qwen3.8-omni-flash`，Flash / Max 会明确拒绝音频请求。Omni 的供应商 SSE 在服务端内部收集为完整听评文字，正常文字与供应商思考输出都会续期等待时间；这不意味着 A/B 页面会实时显示逐字回复，也不改变其用户确认上传的流程。

返回 `status`、`provider`、`model`、`review`、`message`；失败时另含 `errorCode`，HTTP 失败还含 `httpStatus`。`status` 为 `ok`、`not_configured` 或 `error`。只有 `ok` 才含模型听评文本。缺少配置、超时、静音判断困难或接口错误时，不生成虚构听感。错误不会回显供应商响应正文、认证头或完整 URL，计费请求不自动重试。

调用入口负责白名单路径和上传授权。模型收到的是实际音频文件，但其听感描述仍可能出错；本模块不会自动执行返回的参数建议。工程上下文只是辅助资料，不能代替听音，也不能把本地电平变化解释为调教质量改善。

## 从模型建议到工程修改

模型一次最多提出五种不同参数，可使用整体增量 `{parameter,delta,reason}` 或稀疏曲线 `{parameter,curve,reason}`，可选表示方式为 `renderMode=smooth|points`，默认 smooth。曲线是 2～64 个 `[position,value]`，位置为当前连续选区内的 0～1 比例，严格递增且首尾为 0、1。多个局部变化合并在同一参数曲线中，不能让模型自动按词或按字改变宿主选区。提案最初为 `proposed`，点击预览后，服务重新检查桥接会话、目标选区与声库身份、该参数指纹和可用能力，再调用 SynthV 生成实际预览；成功后才成为 `previewed`。此过程不写工程。用户核对范围、单位、曲线和限制，开启工程写入后，逐项确认应用。

输入区的“绘制模式 / 控制点模式”是独立的会话偏好，每次发送固定一份快照，不改写历史提案。模型动作须符合当前模式；控制点模式的音高使用 `pitchDelta`，不能返回原生 `pitchCurve`。绘制模式的原生音高优先使用 `{parameter:"pitchCurve",pitchShape:{curve:[[0,-12],[0.2,0],[0.8,0],[1,-8]],transitionMs:40},reason:...}`：包络是每个音符重复使用的 2～8 个相对音分节点，±50 音分以内；过渡为 5～120 毫秒，默认 40。本机按真实音符秒数和组移调编译为最多 64 节点的绝对曲线，复杂度超限时明确要求缩短选区，绝不丢弃短音符。模型直接提供绝对曲线时，也逐音符在内部 25%、50%、75% 位置检查乐谱音高偏离。

通用参数包括旧五参数及宿主明确支持的 toneShift、vibratoEnv；模型只能使用本次返回的动态声线目录。模式名称和可用性随声库及当前组设置变化，不预设 Cute 等名称；未列出不等于证明整个声库永远不支持该风格，但助手不能猜测名称后写入。通用参数、声线模式与 pitchDelta 的曲线纵轴均为偏移量，边缘由宿主淡入淡出；声线值按百分点表达。具体上限和协议见 [声线参数与曲线编辑](parameter-curves.md)。

官方脚本接口不能保证枚举面板中的全部声线模式。若目录缺少需要的名称，用户应先在 SynthV 当前声库的声线面板核对原名，再在工作台手动补充；名称不含控制字符，去首尾空白后 UTF-8 长度最多 80 字节。补充请求会核对当前工程、音符组和声库身份，只在本次桥接内存中添加目录，不写工程或永久配置。模型会看到 `source=host` 或 `source=user`，前者为宿主返回，后者为用户核对后的声明；模型没有注册工具，也不能把用户补充说成 API 已完整验证该声库的所有模式。

`pitchDelta` 是音分偏移；`pitchCurve` 则是绝对 MIDI 半音，二者不能互换。原生音高只在当前宿主返回 `nativePitch=true` 且对应目录项可用时开放，仅支持 smooth 曲线，并限制在选区实际音域上下各 2 半音与 MIDI 0～127 的交集内。跨界原生曲线、区内引导点或非零 pitchDelta 会使预览被拒绝。实际脚本 API 不可用时按不可用展示，不因已接入模型或文档中存在该 API 就宣称已经支持。

提案与手动工具通过 `web/curves.js` 显示同一套曲线与表示说明。宿主预览最多返回 256 个修改前/后样本；原生曲线未取得修改前生成音高时，只展示已有数据，并明确前值不可用。图形、音符结构和参数指纹都不是录音：没有显式音频附件时，模型不能声称已听过效果；有音频时仍需用户实际试听确认。

预览额外显示当前选中音符的时间范围和含组移调的乐谱音高，便于对照每个音符；此叠层不是测得的演唱基频，也不用于补造缺失的原始音高曲线。

开启“允许修改选区”时，后端先将磁盘上的已保存 `.svp` 复制到本地备份目录，成功后才开启写入；未保存为可访问文件的工程会被拒绝。自动备份不包含未保存的编辑，也不自动保存应用结果；重要工程仍建议先在 SynthV 保存或另存工作副本。

应用前先持久化 `unknown`，再调用宿主；只有宿主确认写后验证成功才记录为 `applied`。超时、断连或进程中断时，结果未知的提案不允许重放。应先在 SynthV 检查实际状态或撤销，再读取选区、重新规划。桥接重启、声库/组移调、音符或目标参数指纹改变时，旧提案需重新生成。

对于明确验证成功的 `applied`，撤销或恢复回原状态后允许重新申请预览。服务必须确认原桥接会话、选区、能力和目标参数完整指纹一致，清除旧结果并退回 `proposed`，再请求新的宿主预览；仍需用户再次确认应用。仅有点数的旧摘要不能证明已经撤销，`unknown` 也不能经此流程解锁。

新宿主预览会使其他旧预览失效。不同参数可逐项预览、确认，但没有多参数原子事务；恢复只针对桥接保存的最后一次修改。选区覆盖的是从第一个选中音符开始到最后一个结束的连续区间，包含其中的间隙和未选中音符；最多 128 个音符、30 秒。新桥接提供完整控制点与插值状态指纹，点数不变的手工改线也可使提案失效；旧桥接缺少该字段时仍只具备旧摘要检查，并仅兼容原五参数增量。实际应用始终严格核对宿主预览时的完整曲线或原生音高快照。

- [Gemini generateContent REST 参考](https://ai.google.dev/api/generate-content)：使用 `contents`、`systemInstruction` 和 `candidates[].content.parts[].text`。本版继续使用该公开接口；未接入另外的 Interactions 或 Live API。
