# Flutter 桌面工作台约定

- 本目录是独立 Flutter Windows 应用，不使用 WebView 包装旧网页。用户明确授权此次迁移；旧网页规范中的“不得新增构建链”仅约束 `web/`，不适用于本目录。
- 保持黑白、中性灰工作台，默认跟随系统主题；曲线图允许有限系列色。控件高度、间距、圆角集中在共享主题中。
- 采用工业软件式工具栏与属性面板：标题栏 38、页面工具栏约 48、控件 34、状态栏 28，主体字号 13、普通圆角 4。内容依靠分组标题和单分隔线建立层级，不叠加大卡片与重复边框。
- 功能页复用 `pages/page_chrome.dart`；属性名放在控件外，窄面板自动改为上下排列。连接状态集中在状态栏，诊断和目录管理有独立主页面；参数节点和长说明按需展开。
- 工程与参数使用独立主页面，不恢复常驻右侧检查器；页面首次打开后保留草稿，隐藏期间暂停轮询。会话方案以单一主操作推进预览、确认应用与指定批次撤销；失败项不得自动排除后应用。
- 音高策略与曲线表示方式分开：默认保留原音高，偏差微调和原生重绘不能互换。预览显示宿主最终参数值，不能将音分偏差误标为绝对音高或最终演唱基频。
- 下拉选择统一使用 `widgets/workbench_dropdown.dart` 的 `WorkbenchDropdown`，约束可见 InputDecorator 边框高度及正文字重；不能仅用外层 SizedBox 掩盖内部高度差，也不再逐页重复派生样式。
- 展开区域统一使用 `widgets/workbench_expansion_tile.dart` 的 `WorkbenchExpansionTile`，各条目提供独立 `storageId`。展开状态与内部 TextField/SelectableText 滚动存储必须隔离，禁止直接复用祖先滚动视口的 PageStorage 键。
- 模型服务采用平台列表与详情分栏，连接配置与模型目录分组；宽度不足时切换列表/详情。平台协议、启停和新会话默认是不同概念，不合并为同一选择框。
- 会话模型通过同一选择器原子确定平台与型号；默认选项须展示实际模型 ID。目录搜索只查缓存，只有明确动作才获取供应商目录或测试连接。
- 设置页离开、平台切换及重载共用草稿保护；固定操作栏明确已保存、未保存和保存中。连接已配置、默认模型已配置、目录测试成功不能混为同一种状态。
- 管理操作统一图标与中文 Tooltip；主要动作保留文字。长内容可换行，列表独立滚动，输入区与确认区保持可见。
- 全部代码包含具体、规范的中文注释。通过 core/api.dart 连接本机服务，不绕过 Python 校验、预览、确认、密钥加密与历史资料保护。
- 模型调用与宿主写入只能由用户动作触发。音频入口已退役，不能通过旧页面、HTTP 路由或 MCP 工具重新启用；已有本地文件不得自动删除或外发。测试使用模拟接口和隔离数据，不自动重试付费请求。
- 运行 flutter analyze、flutter test、Windows release 构建；视觉验收不得将私人资料或截图提交仓库。
