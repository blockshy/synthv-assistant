# Flutter 桌面工作台约定

- 本目录是独立 Flutter Windows 应用，不使用 WebView 包装旧网页。用户明确授权此次迁移；旧网页规范中的“不得新增构建链”仅约束 `web/`，不适用于本目录。
- 保持黑白、中性灰工作台，默认跟随系统主题；曲线图允许有限系列色。控件高度、间距、圆角集中在共享主题中。
- 管理操作统一图标与中文 Tooltip；主要动作保留文字。长内容可换行，列表独立滚动，输入区与确认区保持可见。
- 全部代码包含具体、规范的中文注释。通过 core/api.dart 连接本机服务，不绕过 Python 校验、预览、确认、密钥加密与录音保护。
- 模型调用、宿主写入和上传音频只能由用户动作触发。测试使用模拟接口和隔离数据，不自动重试付费请求。
- 运行 flutter analyze、flutter test、Windows release 构建；视觉验收不得将私人资料或截图提交仓库。
